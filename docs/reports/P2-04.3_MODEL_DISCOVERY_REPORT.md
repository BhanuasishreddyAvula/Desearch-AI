## 2. Universal Model Resolution Logic

The `resolve_active_model()` function guarantees that `404 NOT_FOUND` errors are permanently eliminated:

1. **Exact Match**: Checks if the requested model name is active on the API key.
2. **Variant Match**: Checks if `{requested_model}-latest` is available.
3. **Priority Fallback**: Evaluates `gemini-2.0-flash`, `gemini-2.0-flash-exp`, `gemini-1.5-flash-latest`, `gemini-1.5-flash`, `gemini-1.5-pro`.
4. **Flash Match**: Matches any model containing `flash`.
5. **Generative Match**: Resolves to the first available `generateContent`-capable model for that API key.
