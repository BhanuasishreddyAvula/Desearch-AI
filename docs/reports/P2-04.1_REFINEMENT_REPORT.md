## 2. Configuration Changes

- **Primary API Key**: Added support for explicit `GOOGLE_API_KEY` environment variable in `.env` (with fallback to `API_KEY`).
- **Startup Log Validation**: Backend logs an `ERROR` on startup if `GOOGLE_API_KEY` is missing without crashing.
- **Request-Time Failure**: Calling `POST /api/v1/planner/plan` without a valid `GOOGLE_API_KEY` raises `ConfigurationException` (`HTTP 500`), returning a standardized `ErrorResponse` envelope (`success = false`).

## 3. Gemini Model Upgrade

- Upgraded default model identifier from `gemini-1.5-flash` to **`gemini-2.5-flash`**.
- Configured JSON schema generation via `response_mime_type: "application/json"`.

---

## 4. Complete Removal of Fallback Planner

- Completely deleted `_generate_fallback_plan()` from `planner.py`.
- The Planner Agent **never** fabricates a local plan.
- All Gemini API errors (timeout, rate limit, empty response, invalid JSON) explicitly raise standardized exceptions (`ExternalServiceException` or `ValidationException`).
