## 5. LLM Client Design (`app/core/llm/client.py`)

- **Direct HTTPX REST API**: Sends HTTP POST requests directly to OpenRouter `/chat/completions` endpoint without vendor SDKs.
- **Normalized Output (`LLMResponse`)**: Returns normalized response containing content string, model name, provider name, latency in milliseconds, and token usage counts (`prompt_tokens`, `completion_tokens`, `total_tokens`).
- **Standardized Exception Mapping**:
  - `401`: `AuthenticationException`
  - `403`: `AuthorizationException`
  - `404`: `ResourceNotFoundException`
  - `429`: `RateLimitException`
  - `408 / 504`: `ExternalServiceException` (Timeout)
  - `500 / 502 / 503`: `ExternalServiceException`
